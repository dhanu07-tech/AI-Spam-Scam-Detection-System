# 🛡️ AI-Spam-Scam-Detection-System
## 📌 Overview
An AI-powered web application that detects,phishing,and scam messages using Python,Streamlit,Machine Learning ,and rule-based techniques.

## ✨ Features
- Email Spam Detection
- Phishing Detection
- WhatsApp Scam Detection
- QR Scam Detection
- Risk Score Generation
- Prediction History

- ## 🛠️ Technologies
-  Python
-  Streamlit
-  Scikit-learn
-  Pandas
-  Plotly

## 🚀 Run the Project

'''bash
pip install -r requirements.txt
streamlit run spam_scam_detector.py
'''
